# install-icons

Installa il tema icone Fluent con tutte le varianti colore in `/usr/share/icons`,
scaricandolo dal repository upstream pinnato a un commit specifico per build riproducibili.

Per aggiornare il tema, sostituisci `FLUENT_SHA` nello script con il commit upstream desiderato
(la cartella di estrazione viene rilevata dinamicamente, nessun altro cambio necessario).
