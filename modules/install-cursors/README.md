# install-cursors

Installa il tema cursori ArcDusk e lo imposta come cursore di default
(`/usr/share/icons/default/index.theme`), scaricandolo dal repository upstream
pinnato a un commit specifico per build riproducibili.

Per aggiornare il tema, sostituisci `ARCDUSK_SHA` nello script con il commit upstream desiderato
(la cartella di estrazione viene rilevata dinamicamente, nessun altro cambio necessario).
